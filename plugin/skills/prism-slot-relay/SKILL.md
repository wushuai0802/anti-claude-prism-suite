# Prism 多账号槽位接力与主目录同步规范

本技能依托 `prism-files_files` MCP 服务的 `prism_memory_list`、`prism_memory_store`、`prism_memory_search` 与 `prism_quota_sync` 工具，在同一台设备跨账号或跨模型家族切换时，复用同一本地项目工作区实现无损接力。

## 1. 目录骨架与槽位标签约定

- **共用本地代码库**：不同账号共用同一本地项目目录（或显式标注的独立 Git worktree），不复制冗余仓库副本。
- **主目录轻索引标签**：固定使用 `catalog:master` 维护全局「项目标识 → 本地规范路径 → 活跃槽位 → 槽位标签」轻索引，仅存结构化目录映射，不堆砌聊天长文。
- **槽位交接标签格式**：统一采用双标签 `project:<project>` 与 `handoff:<project>:<slot>`，确保按槽位精准隔离检索。

## 2. 标准口令与执行流水线

### 口令一：`同步主号目录`

1. 调用 `prism_memory_list` 过滤标签 `catalog:master`，拉取最新主目录索引；
2. 以精炼表格向用户展示当前已登记的项目路径、槽位名称、对应标签与最近活跃状态；
3. 若用户在本次对话中新建或归档了长期槽位，调用 `prism_memory_store` 更新 `catalog:master` 条目。

### 口令二：`绑定槽位 [<槽位>]`

1. 解析目标项目 `<project>` 与槽位名 `<slot>`，确认绑定精确标签 `handoff:<project>:<slot>`；
2. 核对目标本地工作目录存在且可访问，向用户返回简明绑定确认，并将该槽位作为当前会话后续交接读写的固定归属。

### 口令三：`接力` / `接力 [<槽位>]` / `继续`（防旧里程碑误导）

跨账号切回或新会话接手时，严格按以下三步还原现场，严禁跳过核对直接改代码：

1. **按精确标签时间倒序拉取（主通道）**：
   - 优先调用 `prism_memory_list` 指定精确标签 `handoff:<project>:<slot>`，按时间倒序取最新的 **1–2 条**交接记录；
   - **严禁仅用 `prism_memory_search` 语义搜索替代精确列表拉取**，防止高权重的早期阶段性里程碑排在前面掩盖最新半成品进度（`prism_memory_search` 仅在需要回溯历史背景决策时辅助调用）。
2. **核对本地 Git 与状态文件实况**：
   - 检查目标工作目录的 `git status`、当前分支、最新 commit 短 SHA 及项目内状态文档（如 `STATUS.md`）；
   - 若交接记录与本地磁盘实况存在出入，一律以本地真实代码与 `git status` 为准，并在回执中明确说明差异。
3. **先亮 3 行对齐回执再动手**：
   - 动手修改任何文件前，首轮先向用户输出标准 3 行回执：
     ```text
     已对齐 [<槽位>]（来自 <交接时间戳> 交接）
     工作目录：<项目或 worktree 路径> ｜ Git 现场：<分支名 / 未提交改动摘要>
     上次进度：<已完成验证摘要> ｜ 现在继续：<本轮直接动作>
     ```

### 口令四：`准备切号`（含低额度预警自动交接）

当用户主动发送 `准备切号`，或在阶段收尾巡检发现 7d 窗口剩余 ≤ 5% / 5h 窗口剩余 ≤ 10% 时：

1. **同步额度快照**：调用 `prism_quota_sync` 刷新本地账号池额度与重置时间快照（距重置 ≤ 6 小时视为 5h 窗口，> 6 小时视为 7d 窗口），便于用户在工作台挑选接力账号或切换另一独立模型家族；
2. **写入 4 要素脱敏交接记录**：调用 `prism_memory_store`（附带标签 `["project:<project>", "handoff:<project>:<slot>"]`），完整记录以下 4 要素：
   - **要素 1 · 槽位标识与精确时间戳**：`<project>:<slot>` 及 ISO-8601 时间戳；
   - **要素 2 · 实际工作目录**：主仓库路径或具体 worktree 绝对路径；
   - **要素 3 · Git 状态快照**：当前分支、最新 commit 短 SHA、已修改/未跟踪半成品文件清单；
   - **要素 4 · 有效验证证据与下一步动作**：已通过的测试命令摘要，以及下一账号上线后的首个直接执行步骤。

## 3. 隐私与凭据脱敏红线

- 写入 `prism_memory_store` 的一切记忆条目必须 **100% 脱敏**；
- 严禁记录任何 OAuth Token、API Key、Cookie、数据库密码、恢复码、私钥或 `.claude` / `.codex` / `.cc-switch` 内的受保护凭据值（仅允许记录必要的非敏感机制说明或配置项键名）。
